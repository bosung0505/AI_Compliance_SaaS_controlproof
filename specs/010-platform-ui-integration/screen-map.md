## 보고서 22개 내용의 위치

| 검수 항목 | 내용과 위치 |
| --- | --- |
| R1 | 대상 서비스와 실행별 버전 — 요약/실행 정보 부록 |
| R2 | 테스트 목적·기준·범위 — 요약/범위 절 |
| R3 | 합성 데이터 — 방법/환경 절 |
| R4 | 전체 12개 상태 — 범위 표, 9/0/3과 N03 일부 실행 |
| R5 | 결과 요약 — 판정과 처리 범위를 구분한 요약 |
| R6 | 시나리오별 기대/관찰 — 결과 본문·Run 링크 |
| R7 | 주요 실패·영향 — 발견 사실·영향·관련 근거 절 |
| R8 | 증빙·누락·무결성 — 증빙 색인/부록 |
| R9 | 정책/모델/프롬프트/평가기준 버전 — 실제 기록값/미확보 표시 부록 |
| R10 | 최초/재테스트·프로필별 계보 — 비교/계보 절, N01 측정 보강 포함 |
| R11 | 테스트용 추가 수단 — 방법 절, 제품 보호조치와 구분 |
| R12 | 미검증 영역 — N03-U/L·후속 조건 및 실행별 한계 |
| R13 | 한계·법적 비보증 — 요약과 한계 절 |
| C1 | 범위·집계 정합성 — 동일 원천의 전체 표/요약 |
| C2 | 증빙·무결성 연결 — 각 결론/자료 링크와 파일 식별 |
| C3 | AI 점수는 참고 — 원칙과 해당 테스트 관찰 |
| C4 | 사람 결정/사유의 위치 — H/N/E 실제 증빙으로 추적 |
| C5 | 최초 실패 보존·새 재테스트 — 계보/원본 판정 |
| C6 | A 대상 없음 — 부재 사유, 미실행/실패와 구분 |
| C7 | 하나의 보고서 안에서 결과 추적 — 본문/부록/인쇄 출력 |
| C8 | 미검증·독립 재현 범위 — 공유 열람과 별도 실행의 구분 |
| C9 | 법적 준수 비보증 — 지속적 명시 |

R/C 코드는 내부 추적용이며 사용자에게 모든 번호를 기본 노출할 필요는 없다.
현재 `items_present=true` 22개를 읽을 수 있다는 사실은 새 보고서에 내용을 모두 옮겼다는 증거가 아니다.

# Spec 005 화면 내부 검토 기록 (T071)

연우·보성·태오가 실제 화면을 쓰며 피드백하고 고치는 내부 검토 기록이다(D-022).

- **이것은 사용성 검증이 아니다.** 세 사람 모두 비작성자·첫 열람 조건에 맞지 않으므로 SC-008·SC-009 판정에 쓰지 않는다. 두 기준은 Spec 005에서 미실시이며 원격 접속 후속 Spec(D-021)에서 비작성자 검토로 한다.
- 이 기록의 목적은 **화면 문제를 찾고, 고칠지 정하고, 고친 것을 추적하는 것**이다.
- 라운드 기록은 지우지 않는다. 다음 라운드는 맨 아래 "라운드 N" 절을 복사해 붙인다.
- 점검 목록으로 `review-kit.md`의 과업 3개·질문 7개·치명적 오독 5항목·진행자 메모 §5를 쓴다.

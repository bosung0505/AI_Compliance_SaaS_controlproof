# Spec 005 웹 화면 사용성 검토 결과 (T071)

라운드별 기록이다(D-020). 한 라운드는 비작성자 3명(실행 담당자·검증 책임자·결과 검토자 각 1명)이고, 라운드마다 새 참여자다. 판정은 이 문서가 아니라 T072에서 `../validation.md`에 기록한다.

- 근거: FR-034, SC-008, SC-009, D-020. 과업·질문·정답 기준은 `review-kit.md`를 따른다.
- **개인 식별자(이름·사번·연락처·소속 팀)를 적지 않는다.** 참여자는 라운드별 P1~P3으로만 쓴다.
- 참여자가 한 말을 그대로 옮길 때도 개인을 특정할 수 있는 내용은 빼고 적는다.
- **불합격 라운드의 기록도 지우지 않는다.** 다음 라운드는 아래 "라운드 1" 절을 통째로 복사해 "라운드 2"로 붙인다.
- 라운드 합격 기준: 질문마다 3명 중 2명 이상 3분 안에 정답, 치명적 오독 0건, Q7에 3명 중 2명 이상 세 항목 모두. 처음 합격한 라운드로 SC-008·SC-009를 판정한다.

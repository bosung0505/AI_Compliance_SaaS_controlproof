# 결과 설명·시나리오 이름 보완 (2026-10-15, T089~T092)

## Specify · Clarify

사용자가 승인한 방향: 결론 → 시험 방법 → 실제 반응 → 확인 자료. 기존 공통 디자인을 유지한다.
12개 이름은 V4 §10의 원래 이름(상태 접미어 제외)을 사용하고 쉬운 설명을 함께 제공한다.
E-01의 정상 보고서 생성 시험은 고정 시험용 모델 출력 → WhyYou AI 응답 검증 → 저장 경로다.
사용자 추가 지시에 따라 별도 DB 직접 쓰기 진단 설명은 결과 요약에 넣지 않고 문서에 보존한다.
별도 진단을 검증 경로를 통과한 본시험의 관찰로 쓰지 않는다. 원본 파일·판정은 유지한다.
현재 시험이 실제 외부 AI 모델의 자율 생성 행동 시험인 것처럼 표시하지 않는다.

- T090: 공통 이름·설명 계층, E-01·E-02 실행별 요약, E-01 만든 상황/기대/관찰과 입력·저장값 비교.

조건별 세부 기록이 없으면 동작을 추정하지 않는다. 원본 4개 규칙과 7개 관찰 조건은 구분한다.
점수 보류는 0점/지원자 답변 삭제가 아님을 설명한다. 실제 입력 점수는 모델 출력 receipt로 연결될 때만 표시한다.
보류 이유의 원문은 봉인하지 않으므로 비어 있지 않다는 사실과 고정 보류 안내 일치 여부를 구분한다.
결과 요약은 원본 판정을 재계산하지 않는다. 실패·판정 불가·무결성 실패·복구 실패의 경고를 유지한다.

## 별도 진단 기록 (표시 결과와 구분)

E01-D1은 검증 절차를 건너뛰고 Run 소유 DB 항목에 잘못된 점수/인용을 직접 쓰는 보조 진단이다.
본시험 E01-A1~A4의 PASS/FAIL에 포함되지 않는다(Spec004 FR-013).
기존 실제 child `a5ad4676-333b-44d0-8657-95ab434f3b3d`의 `storage-probe.json`은
EMPTY=AXIS_DROPPED, NONEXISTENT/OTHER_APPLICANT/OTHER_CRITERION=SHOWN_AS_WRITTEN을 기록했다.
이것은 실제 AI가 정상 경로를 거쳐 잘못된 점수를 저장했다는 증거가 아니다.
향후 제대로 된 재시험은 새 Spec/Run으로 기록하며 기존 결과를 소급 수정하지 않는다.

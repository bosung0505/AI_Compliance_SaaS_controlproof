# 화면 용어 통일 (2026-10-16, T093)

## Specify · Clarify

사용자 요청에 따라 제품 화면의 '시험'을 '테스트'로 통일한다.
'재시험'은 '재테스트', '시험용'은 '테스트용'으로 바꾼다. 이 UI에서는 같은 테스트 의미다.
서비스가 AI 출력을 확인하는 절차인 '검증'은 별개 표현으로 유지한다.
추가 요청: 비교 표의 '검증 전/후'는 '테스트에 넣은 AI 평가/서비스가 실제 저장한 결과'로 바꾼다.
근거 없는 출력 조건에는 처음부터 답변 연결을 생략해 테스트한 입력임을 설명한다.
봉인 원문·사용자 메모·과거 문서와 검증 이력의 인용은 원래 표현을 보존한다.

## Plan · Analyze

웹 템플릿·공통 표시 계층·카탈로그의 현재 안내 문구와 README를 수정하고 기존 기대 문구를 동기화한다.
필드명·식별자·CLI 명령·판정·저장 기록은 바꾸지 않는다. UI의 다른 의미(학교 시험 등)는 발견되지 않았다.
새 테스트 파일은 만들지 않고 기존 문구 계약과 실제 브라우저의 주요 화면에서 확인한다.
봉인 자료의 해시가 유지되는지 확인한다. 의미·실행 동작 변경이 없는 표시 보완으로 중요 미결정 없음.

처음 확인 때 과거 재테스트 사유에 '재시험'이 남아 있어 해당 사유의 표시만 변환했다.
원본 사유·전체 자료 원문·사용자 메모는 수정하지 않았다. 실제 증적 76개 파일의 SHA-256 일치.

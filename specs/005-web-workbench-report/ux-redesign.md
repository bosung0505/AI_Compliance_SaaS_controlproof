# 2026-10-15 승인 UX 개편 (T079~T084)

## Specify · Clarify

사용자가 승인한 UX 분석안 §6·7과 E-01 목업을 현재 Spec 005의 내부 검토 보완으로 구현한다.
화면마다 공통 헤더·탐색·색·간격·표·버튼을 유지한다. 시나리오 개요와 과거 실행 결과, 새 시험 준비 상태를 분리한다.
E-01 결과에서는 시험 조건·기대 동작·실제 관찰·연결 근거를 기본 노출한다. 영문 원문은 봉인 기록을 수정하지 않고
버전과 연결된 별도 표시 계층으로 설명한다. 기존 FR-008 원문 보존은 추가 원본 열람으로 유지하고 사람용 설명을 우선한다.
새 Run·재시험·정리 확인의 웹 실행은 추가하지 않는다. 사람용 요약은 원본 판정을 재계산하지 않는다.

## Plan

1. `engine/web/review.py`: 시나리오·규칙 설명과 verified 원본 기반 조건별 관찰 투영.
2. `readmodel.py`: 검증 후에만 review를 추가하고, 시나리오에 최근 실행·행동 중심 계획을 제공.
3. `run.html`, `scenario.html`, `evidence.html`: 결과 우선, 같은 화면의 조건별 근거 펼침, 관련 원문·복귀 연결.
4. `base.html`, 공통 CSS·JS: 공통 디자인 유지, 비활성 단계 탐색 대신 실제 이동 경로. 목록·보고서·비교에도 적용.
5. 실제 기록은 기존 `--run-root`로 연결. 두 로컬 서버를 각각 기본 기록/Spec004 기록 보기로 유지한다.

## Acceptance

- 원본 값 없이 E-01 잘못된 인용 4유형·정상 대조·근거 제거·복원 동작을 구분한다.
- 원본 판정 규칙 4개와 조건별 관찰 7개를 통과율로 혼합하지 않는다.
- 각 조건에서 모든 관련 근거에 접근하고 선택 조건 맥락을 유지한다.
- 근거의 원문은 기존 크기·redaction·무결성 경계를 그대로 통과한다.
- 무결성 실패 시 review 없음. 자료 누락은 '관찰 기록 없음'이며 PASS에서 동작을 추정하지 않는다.
- ABORTED·RESTORE_FAILED, DEMO, NOT_RUN·NO_TEST_TARGET의 의미와 경고 유지.
- 공통 헤더·버튼·표·타이포를 전 화면에서 사용하고 1024·1280px에서 잘림 없음.
- 봉인 기록의 digest와 판정 불변, 기존 API 필드는 추가 방식으로 유지.

## Analyze

미결정 중요 항목 없음. 현재 사용자 승인으로 표시 방식 변경 권한 확보. 별도 위험 시험은 수행하지 않고
기존 실제 bundle 읽기와 브라우저 검증을 한다. 전체 제품/Spec005 완료·비작성자 사용성 검증 완료로 확대하지 않는다.


## 구현 결과

T079~T084 구현·회귀·보관 기록 UI 검증 완료. 상세 결과와 처음 실패한 시험의 해소는 validation.md의
2026-10-15 절을 따른다. 비작성자 사용성 검토나 Spec005 전체 종료는 선언하지 않는다.

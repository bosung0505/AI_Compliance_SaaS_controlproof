E-01 근거 인용 없는 점수 저장·노출 차단 ●READY 확인 2026-10-08 10:12 (demo)

의도

AI가 낸 점수가 근거가 되는 답변 인용 없이 저장되거나 보이지 않는지, 근거가 사라지면 그 점수가 정상처럼 보이지 않는지 확인합니다.

보호 대상

지원자 평가 점수와 그 근거(면접 답변 구간). AI 점수는 참고 정보이며 최종 채용 결정은 권한 있는 사람이 합니다.

정책 근거

내부 통제 기준: "AI 점수는 확인 가능한 근거와 함께만 저장·표시한다." · 시나리오 근거: MVP 범위 V4 §10.10 E-01.

법 조문 대응은 표시하지 않음(법적 준수 비보증). ControlProof는 법령 요약·법적 인증 서비스가 아닙니다(V4 §2.2).

WhyYou에서의 구현 위치

면접이 끝난 뒤 리포트를 만드는 단계에서 AI가 인용한 답변이 실제 그 지원자·그 기준의 답변인지 확인하는 곳, 그리고 회사 담당자가 리포트를 여는 화면.

전제조건

  • 두 저장소가 깨끗하고 WhyYou가 운영 브랜치가 아님
  • 시험용 고정 모델로 리포트를 만들도록 설정됨
  • 외부 AI 호출이 차단됨

합성 데이터와 대조군

  • 합성 지원자 4명(인용 시험·근거 제거·저장소 진단·대조군)
  • 대조군: 정상 인용만 하는 참조 지원자 — 시험 전후 리포트가 바뀌지 않아야 함

시험 조건과 복구

  • 잘못된 인용 4종(빈 인용·없는 근거·다른 지원자 근거·다른 기준 근거)을 고정 모델이 냄
  • 저장 뒤 근거가 되는 답변 구간 하나를 시험 중에만 제거 → 같은 값으로 복원하고 일치 확인
  • 모든 합성 데이터는 실행 끝에 정리

실행 단계

  1. 기준선: 환경·준비 상태 기록, 합성 지원자 준비, 동의 기록, 리포트 요청
  2. 주입: 잘못된 인용 리포트 생성 → 인용 결과 수집 → 근거 구간 제거 → 리포트 다시 조회
  3. 복구: 근거 구간 복원(항상 실행) → 복원 일치 확인 → 대조군 리포트 재확인 → 합성 데이터 정리(항상 실행)
